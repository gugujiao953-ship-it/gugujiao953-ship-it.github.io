# GitHub 个人主页

这个目录是一个可直接发布的静态个人主页初版，适合放到 GitHub Pages。

## 使用方式

1. 新建一个仓库，仓库名使用 `gugujiao953-ship-it.github.io`
2. 把这个目录里的文件上传到仓库根目录
3. 提交后等待 GitHub Pages 自动发布
4. 发布地址通常是 `https://gugujiao953-ship-it.github.io/`
