# 肖振 · 设计作品集

版本：2026-10-16。

## 打开与浏览

双击本目录的 index.html，用 Edge、Chrome 或 Safari 打开。无需安装依赖，也无需运行命令。请保留完整文件夹结构；发送给别人离线查看时，发送整个 ZIP 并请对方先解压。

如果正在浏览旧版网页，刷新页面即可看到更新。必要时使用 Ctrl+F5。

## 本版内容

- 11 个精选项目、93 张主站展示图，按 UI / UX、品牌策划、文化与 IP、儿童文创、平面视觉、影像与摄影分类。
- 半步五子棋打谱位于作品列表第一位，以独占一行的大卡片展示；画里星芒位于整体第二位。首页主按钮直接打开半步项目详情。
- 半步详情提供重点图文、传播与社群数据，并可打开完整的 34 页设计案例。完整案例在 cases/banbu/index.html，附带全部所需资源，可离线查看。
- 新增一品忘忧品牌方案、应县木塔 IP、蝶梦苗族香道三件套、豚宝聚财罐、夏小满的田园。
- 已移出 AI 绘画练习、PS 图片处理作业、四格漫画等项目。原始作业文件没有删除或修改。
- 保留《画里星芒》合作短片播放器，以及此前完成的 AI 辅助设计版简历下载。

半步项目直达地址：在主站 index.html 后加 #project/banbu。它的完整案例右下角有返回作品集按钮。

## 维护文件

- projects.js：项目标题、文案、分类、排序和图片编排。
- index.html：首页文案、技能介绍、联系方式和主入口。
- style.css、revision.css：基础样式与新版项目、移动端样式。
- media.js、assets/：主站图片索引、图片和视频文件。
- app.js：筛选、详情、图片浏览和跳转逻辑。
- cases/banbu/：半步独立案例与全部依赖资源；移动这个目录时应保持相对路径。
- 肖振_个人简历.docx：当前下载的简历文件，后续可替换同名文件。

## 操作

- 点击项目进入详情；点击图片放大。
- Tab 移动焦点，Enter 打开按钮或链接。
- 大图中使用左右方向键切换；Esc 先关闭大图，再关闭详情。
- 半步完整案例支持目录跳转、放大细看和图层示意切换。

## 发布与简历二维码

当前交付为本地静态网站，尚未公开部署。将完整文件夹发布至静态网站空间后，用稳定的 HTTPS 网址生成简历二维码。部署时需一并上传 assets 和 cases 目录。

二维码可以指向作品集首页；如果投递岗位特别看重 UI / UX，也可指向首页地址加 #project/banbu。先在手机上验证网址，再放入简历。本地 file 路径不能供招聘方扫码访问。
