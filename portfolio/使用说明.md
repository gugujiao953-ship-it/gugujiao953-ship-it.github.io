# 肖振 · 设计作品集

版本：2026-10-16 深色沉浸式版。

## 打开与浏览

双击本目录的 index.html，用 Edge、Chrome 或 Safari 打开。请保留完整文件夹结构；发送给别人离线查看时，发送整个 ZIP 并请对方先解压。

首页先提供六个作品方向入口：UI / UX 与产品、AI 漫剧与影像、品牌与包装、文化与 IP、儿童文创、平面视觉。点击入口会跳到对应筛选结果；继续向下滚动会按顺序完整展示所有项目。

## 维护文件

- projects.js：项目文案、分类、顺序和图片编排。
- index.html：开屏、分类入口、创作方式、联系方式和下载入口。
- immersive.css：深色沉浸式视觉、卡片、动画和响应式布局。
- media.js、assets/：图片索引和媒体文件。
- app.js：分类筛选、详情弹窗、图片灯箱和半步跳转。
- cases/banbu/：半步完整案例及全部依赖资源，移动此目录时请保持相对路径。

## 操作

点击开屏方向或筛选按钮可快速浏览；点击项目卡片查看完整说明和图片；图片支持放大与左右切换；按 Esc 分层关闭大图和详情。半步完整案例支持目录跳转、放大细看、图层示意切换和返回主站。

## 发布与简历二维码

部署时需一并上传 index.html、immersive.css、app.js、projects.js、media.js、assets 和 cases 目录。稳定 HTTPS 地址确认后，再用该地址生成二维码；本地 file 路径不能供招聘方扫码访问。
